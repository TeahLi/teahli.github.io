# 李林鸿个人主页（双布局 GitHub Pages 正式版）

本目录可直接作为 GitHub Pages 仓库根目录使用。

## 布局

- 默认：长滚动个人主页
- 点击 `STYLE SWITCH / 风格切换`：切换到分页册页布局
- 在分页册页布局中再次点击同一按钮：返回长滚动布局
- 两种布局均保留中英文切换、昼夜切换与动态星空效果

## 文件结构

- `index.html`：正式主页（包含两种布局）
- `support.js`：页面运行时
- `assets/`：星空、水墨峡谷和小舟素材
- `.nojekyll`：让 GitHub Pages 按静态文件原样发布

## 发布

把本目录中的文件上传到 GitHub Pages 仓库根目录；在 Settings → Pages 中选择：
Deploy from a branch → `main` → `/ (root)`。
